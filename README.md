# Fashion-MNIST CNN Structured Pruning

基于 PyTorch 的卷积神经网络结构化剪枝实验。通过卷积通道重要性评估、通道裁剪和微调，研究模型压缩对分类准确率、参数量、计算量及实际推理性能的影响。

## 1. 项目简介

本项目以 Fashion-MNIST 数据集为实验对象，构建基础 CNN 分类模型，并对卷积层进行两阶段结构化剪枝。

项目主要目标：

- 实现基于权重重要性的卷积通道剪枝。
- 通过微调恢复剪枝后的模型精度。
- 对比剪枝前后的参数量、MACs 和模型文件大小。
- 在 CPU 和 CUDA 环境下测试推理延迟与吞吐量。
- 分析理论计算量减少与实际推理性能之间的关系。

## 3. 模型与剪枝方法

### 3.1 基础 CNN

模型包含两层卷积层和两层全连接层，用于 Fashion-MNIST 十分类任务。

| 网络层 | 原始结构 |
|---|---|
| Conv1 | 1 → 16 通道 |
| Conv2 | 16 → 32 通道 |
| FC1 | 1568 → 128 |
| FC2 | 128 → 10 |

### 3.2 两阶段结构化剪枝

**第一阶段：剪枝 Conv1**

根据卷积核权重绝对值之和评估各输出通道的重要性，移除重要性最低的 4 个通道，将 Conv1 的输出通道从 16 减少到 12，并同步调整 Conv2 的输入通道。

**第二阶段：剪枝 Conv2**

进一步将 Conv2 的输出通道从 32 减少到 24，并同步调整后续全连接层的输入特征，形成更紧凑的网络结构。

每阶段剪枝后均进行微调，以尽可能恢复模型的分类性能。

## 4. 实验结果

以下为当前实验记录中的测试集结果。

### 4.1 分类准确率与模型规模

| 指标 | 原始模型 | 第一次剪枝并微调 | 第二次剪枝并微调 |
|---|---:|---:|---:|
| 测试准确率 | 90.47% | 90.86% | 90.90% |
| 参数量 | 206,922 | 205,730 | 154,682 |
| MACs | 1.2180 M | 0.9640 M | 0.7445 M |
| 权重文件大小 | 0.7930 MB | 0.7888 MB | 0.5941 MB |
| 相对原始模型的参数量减少 | 0.00% | 0.58% | 25.25% |
| 相对原始模型的 MACs 减少 | 0.00% | 20.85% | 38.88% |

注：

- FLOPs 按每次 MAC 对应 2 FLOPs 的口径估算。
- 模型文件大小为当前实验环境下保存的权重文件大小。
- 参数量减少比例和 MACs 减少比例均以原始模型为基准。

### 4.2 实验结果分析

第二次剪枝模型相较原始模型，参数量减少约 25.25%，MACs 减少约 38.88%，权重文件大小减少约 25.08%。

测试准确率从 90.47% 提高到 90.90%，提高了 0.43 个百分点。当前实验结果表明，在本次实验设置下，结构化剪枝能够减少模型规模和理论计算量，同时保持分类精度。

## 5. 推理性能分析

推理性能通过重复测量进行评估，分别测试 CPU、CUDA，以及 Batch Size 为 1 和 64 的情况。当前实验使用 20 次重复测量，并统计平均延迟、延迟标准差及平均吞吐量。

### 5.2 推理吞吐量

吞吐量表示单位时间内模型处理的图像数量，单位为 images/second。

![推理吞吐量对比](assets/repeat_throughput.png)

### 5.3 计算量与延迟对比

将理论计算量与实际推理延迟结合分析，可以观察模型压缩效果与硬件执行效率之间的关系。

![计算量与延迟对比](assets/compute_latency_comparison.png)

### 5.4 性能分析结论

从当前实验结果可以观察到：

- 第二次剪枝将参数量减少约 25.25%，MACs 减少约 38.88%。
- 第二次剪枝后的测试准确率为 90.90%，比原始模型高 0.43 个百分点。
- CPU 环境下，第二次剪枝后的模型在当前测试条件下具有更低的推理延迟。
- CUDA 环境下，剪枝模型的推理延迟有所增加，说明参数量和理论计算量减少不一定带来实际 GPU 加速。
- 不同 Batch Size 下，模型的延迟和吞吐量表现存在差异，因此需要结合具体部署场景进行评估。

以上性能结论仅适用于当前硬件、软件环境及测试配置，不代表所有设备上的表现。

## 7. 环境配置

建议在 Python 3.11 环境下运行，并安装与当前 CUDA 环境匹配的 PyTorch 和 Torchvision。

安装项目依赖：

```bash
pip install -r requirements.txt
```

如果尚未配置 PyTorch，请根据操作系统、显卡和 CUDA 环境选择相应的安装方式。

## 8. 运行实验

在项目根目录打开终端。

### 8.1 训练基础模型

```bash
python src/train.py
```

### 8.2 评估基础模型

```bash
python src/evaluate.py
```

### 8.3 运行推理性能测试

```bash
python src/benchmark_inference_repeat.py
```

### 8.4 统计模型计算量

```bash
python src/measure_compute.py
```

### 8.5 生成重复测量图表

```bash
python src/plot_repeat_benchmark.py
```

注意：剪枝和微调脚本需要按照各脚本的权重依赖及执行顺序运行。运行前请确认对应的模型权重文件已经生成，并检查脚本中的模型路径与当前项目一致。

## 9. 实验总结

本项目完成了基于权重重要性的两阶段 CNN 结构化剪枝，并通过微调、测试集评估、计算量分析及重复推理基准测试验证了实验结果。

实验表明，结构化剪枝能够有效降低模型参数量和理论计算量，同时维持当前实验中的分类精度。但模型压缩效果与实际推理加速并不完全一致，仍需结合具体硬件、Batch Size 和推理框架进行评估。
